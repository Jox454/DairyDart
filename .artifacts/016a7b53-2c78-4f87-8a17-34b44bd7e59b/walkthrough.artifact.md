# Реализация статистики и редактирования записей

Я реализовал вкладку **Stats** и добавил возможность редактирования существующих записей настроения.

## Основные изменения

### [NEW] [stats_tab.dart](file:///C:/Users/d/Desktop/Blog/Diary/Code/lib/features/diary/presentation/pages/stats_tab.dart)
- Реализована навигация по месяцам.
- Добавлена секция **Streak** с визуальным отображением прогресса по дням.
- Создан кастомный график **Mood Fluctuations** с использованием `CustomPainter` для отображения динамики настроения за последние 7 дней.
- Добавлена сетка достижений с различными бейджами (Zen Master, On Fire и др.).

### [MODIFY] [add_entry_page.dart](file:///C:/Users/d/Desktop/Blog/Diary/Code/lib/features/diary/presentation/pages/add_entry_page.dart)
- Страница теперь поддерживает режим редактирования. Если передана существующая запись, поля (смайлик, занятия, текст заметки) заполняются автоматически.
- Логика кнопки сохранения адаптирована: она вызывает `updateEntry` для изменений или `addEntry` для новых записей.

### [MODIFY] [mood_tab.dart](file:///C:/Users/d/Desktop/Blog/Diary/Code/lib/features/diary/presentation/pages/mood_tab.dart)
- Пункт меню **Edit** теперь функционален. При его выборе открывается страница редактирования с данными текущей записи.

### [MODIFY] [dashboard_page.dart](file:///C:/Users/d/Desktop/Blog/Diary/Code/lib/features/diary/presentation/pages/dashboard_page.dart)
- Вкладка **Stats** полностью интегрирована в основное меню.

## Как проверить
1. Перейдите во вкладку **Stats**, чтобы увидеть новую аналитику.
2. Во вкладке **Mood** нажмите на три точки (`...`) у любой записи и выберите **Edit**. Вы сможете изменить настроение, занятия или текст, и после сохранения запись обновится.

> [!TIP]
> График статистики использует фиктивные данные для демонстрации интерфейса. В дальнейшем его можно подключить к реальной базе данных через Cubit.
